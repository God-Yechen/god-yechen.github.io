启动：右键运行“启动栏目管理.ps1”，或在 PowerShell 执行该脚本。
管理地址：http://127.0.0.1:4012/private-center/
公开预览：http://127.0.0.1:4000/

解锁后，打开具体专栏或荣誉成果，点击公开／私密，输入同一访问密码确认。
切为私密：文章与专属本地附件转为密文，公开构建中的文章、图片、分类、搜索及订阅记录随构建移除。
切回公开：恢复文章及附件；荣誉成果会生成公开荣誉页和可访问的证书。
首页及专栏总览是汇总页面，应在具体栏目设置。关于我、我的足迹及人生清单也可切换；私密后页面源文件和独立数据会移入加密包。

此过程不会自动 Git 提交或推送。务必先查看公开预览，确认后再发布。
已经公开过的 Git 历史、浏览器缓存或他人保存的副本不会自动清除。
本地原文件备份保存在 .private-local/visibility-backups/（已排除出 Git 和网站）。
使用栏目管理后，旧“设置私人空间”工具会阻止使用旧源文件覆盖新加密包，避免丢失迁移后的文章。
外部图片、被其他公开文章共用的附件和跨栏目的文章会阻止迁移并提示原因，避免误删其他内容。
